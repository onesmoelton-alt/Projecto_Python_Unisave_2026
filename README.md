Sistema de Gestão de Stock

Projeto Académico de Python — UniSave 2026

1. Descrição do projeto

O Sistema de Gestão de Stock é um programa desenvolvido em Python com o objetivo de facilitar o controlo de produtos de um pequeno estabelecimento.

O sistema permite cadastrar produtos, consultar o stock, registar entradas e saídas e guardar automaticamente os dados.

2. Funcionalidades

- Cadastrar produtos.
- Listar produtos cadastrados.
- Registar entradas de stock.
- Registar saídas de stock.
- Verificar a disponibilidade dos produtos.
- Impedir saídas superiores ao stock disponível.
- Guardar os dados num ficheiro JSON.
- Tratar erros na introdução de dados.

3. Tecnologias utilizadas

- Python 3
- JSON

4. Ficheiros do projeto

- "sistema_gestao_stock.py" — código principal do programa.
- "stock.json" — ficheiro criado automaticamente para armazenar os produtos.

5. Como executar o programa

1. Instalar Python 3.
2. Transferir o ficheiro "sistema_gestao_stock.py".
3. Abrir o terminal na pasta onde está guardado.
4. Executar o comando:

python sistema_gestao_stock.py
